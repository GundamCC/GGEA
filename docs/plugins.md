# 本机插件开发与使用

插件系统 API v1 从 GGEA 1.3.2.0 起提供。普通安装不包含任何插件，不访问私有仓库；独立插件只依赖 `GGEA.Plugin.Abstractions`。Billing 自 1.3.3.0 起迁至 GGEA-Extensions，普通程序不再包含其实现与资源。

## 安装与启停

1. 关闭 GGEA，将可信插件完整解压至 `plugins/<id>/`，目录名必须与清单 `id` 完全一致。
2. 启动 GGEA，在“设置 → 本机插件”检查名称、版本和状态，勾选后保存。
3. 重启后才加载插件。停用同样需要保存并重启；卸载前先停用并正常退出，再删除对应目录。
4. 更新插件也必须在程序退出后替换整个插件目录。插件配置保存在 `config/plugins/<id>/settings.json`，不随插件包覆盖。

插件与程序具有相同本机权限，依赖加载隔离不是安全沙箱。只安装你信任的来源。当前不提供签名认证、付费授权、在线市场、自动下载或热加载；安装包获取权限由插件发行者管理。

主程序更新包不能声明 `plugins/` 文件，已有插件作为未知用户文件保留。每次启动重新检查 API 版本和最低宿主版本；后续不兼容协议变更必须递增 API 主版本，不能静默破坏现有插件。

本地“建立普通版本”的原位更新同样保留已安装插件及其配置；新生成的普通分发包不携带这些插件。

## 包结构

```text
plugins/
  ggea.sample/
    plugin.json
    GGEA.SamplePlugin.dll
    GGEA.SamplePlugin.deps.json
    ...插件自身的依赖和资源
```

清单格式见 `samples/GGEA.SamplePlugin/plugin.json`：`apiVersion` 为 1，版本字段使用 .NET 数字版本格式，`assembly` 仅为当前目录的 DLL 文件名，`entryPoint` 为公开、无参构造且实现 `IGgeaPlugin` 的类型。路径穿越和符号链接会被拒绝。未启用的插件只读取清单，不执行构造函数或初始化代码。

启用列表单独存放于 `config/plugins/enabled.json`。损坏的列表不自动恢复为全部启用。缺失或不兼容的插件会显示不可用状态，不加载代码；排查细节见日志。

## 构建示例

```powershell
dotnet build samples/GGEA.SamplePlugin/GGEA.SamplePlugin.csproj -c Debug
```

从 `samples/GGEA.SamplePlugin/bin/Debug/net8.0-windows/` 取示例 DLL、deps.json 与 plugin.json，放入运行目录的 `plugins/ggea.sample/`。示例仅写日志，不操作模拟器，支持编辑连接提示文字。

其他插件可以在自己的仓库引用主仓库中的协议项目；固定主仓库提交作为开发基线。不要引用 GGEA.App、复制宿主实现或分发第二份协议 DLL。第三方依赖使用插件自己的 deps.json 在插件目录解析。

本地验收可设置 `GGEA_PLUGIN_PREVIEW_PACKAGE` 为可信插件包的绝对目录，`GGEA_UI_PREVIEW_DIR` 为截图输出目录，再构建并运行 `ThemeTests`。测试在临时安装目录加载真实 DLL、检查默认配置的设备接入/释放，并渲染深浅主题离屏预览，不访问真实模拟器。此入口用于默认不执行设备命令的插件；不会自动保存设置或覆盖已安装插件。

## 生命周期与状态所有权

- `InitializeAsync`：UI 线程初始化，接收独立配置、日志、插件资源目录与 UI 语言；此阶段没有设备授权。构造函数不应启动后台任务。
- `CreateSettingsEditor`：每次打开设置时创建新视图。编辑期间仅修改草稿；仅 `Save` 才保存，取消窗口不调用。宿主打开设置前等待设备插件收尾，保存或取消后重新同步设备。
- `SetDeviceAsync(device)`：用户明确选择目标后交付不可变设备快照。相同目标刷新不重复建立会话，设备启动标识变化会重新建立。插件自己管理后台任务，并保留任务引用。
- `SetDeviceAsync(null)`：停止并等待旧会话结束。调用结束之前旧通道仍可用于清理；结束后撤销通道，旧引用不可再执行命令。任一插件清理失败都会阻止新设备接入。
- `DisposeAsync`：程序先等待自身任务停止，再逆序清理插件。重复调用应可安全重试；失败不能伪装成功。等待超过 15 秒时窗口保持停止状态，再次关闭继续等待同一清理任务。

设备命令入口固定目标，支持 shell、push、pull；宿主注入设备选择参数并提供 20 秒命令超时、60 秒传输超时和取消。它不授予插件绕过业务消费安全规则的理由。插件不得在后台擅自点击、与普通任务争夺输入，或自行选择其他设备；本机可信插件仍可直接调用系统 API，协议不是权限隔离机制。

初始化失败会尝试释放已创建实例。无法确认清理成功时，禁止接入新设备。设备回调失败会阻止当前操作，不会以“插件被忽略”继续执行游戏任务。设置编辑器出错只影响插件设置展示。

配置使用 JSON 字符串，经语法校验后原子替换，路径由宿主按 ID 分配。插件负责自己的配置版本迁移、字段校验与损坏处理。多个插件设置按顺序独立保存，不是跨插件事务；某个保存失败时，之前成功保存的插件设置仍保留。

## 独立扩展

GGEA-Extensions 独立维护插件实现、资源、配置迁移和测试，主程序只提供公开协议。旧配置中的未知字段原样保留，不由宿主执行。启用插件后由插件导入，并仅恢复当前明确选择设备的历史状态；未连接设备的记录保留待后续选择。

删除当前源码不会删除 Git 历史中的旧实现。开源前仍需单独确定历史处理方案，本次不重写历史。
