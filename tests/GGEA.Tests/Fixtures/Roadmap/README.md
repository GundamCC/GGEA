# 路线图实机回归样本

2026-09-27 从用户授权操作的雷电和蓝叠（1920×1080）ADB 原始截图裁剪，仅保留单位立绘附近画布。采集时蓝叠已按设备属性核实，连接端点为 `127.0.0.1:5555`；不依赖可能重分配的 emulator 别名。

- `target.png`：第一次手动 ADB 拖动后可见的原型高达。
- `after.png`：生产 `DevelopService.FindOnRoadmapAsync` 搜索并连续两帧确认后的原型高达。
- `before.png`：搜索前的吉姆，用于相似单位负例。

测试会明确缩放这些裁剪来模拟不同入场比例；这类合成测试画面不作为实机截图交付。大小两张产品模板保留原尺寸和单位 RGB 像素，仅将背景、光圈、星级与连线设为透明。蓝叠样本用于真实小比例回归，不能只用雷电大图缩小来替代。
