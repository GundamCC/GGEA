GGEA v1.3.3.3 使用说明 — 正式发布 / Release

本版更新：修复初代高达 WebP 缩放边缘与游戏平滑渲染不一致导致的作品漏识别，保持原阈值与身份校验；同一诊断目录共享限频及五槽位轮转，避免不同流程重建实例覆盖彼此最新证据。

大师联盟：在非战斗界面连接设备后，打开“大师联盟”TAB，按需勾选“进行自动编制”和“刷新挑战失败的对手”，点击“开始大师联盟”。默认不刷新；开启后仅在五名对手都已挑战时刷新败北者。刷新会舍弃该对手积分，目标对手积分归零即继续挑战。识别失败、加载超时或设备断开后保留任务并持续重试，可随时中止；已发出的挑战和刷新不会因重试重复发送。未知数字不视为零；挑战/变更次数不足时停止，不自动购买次数。当前只适配简中 1920×1080，其他模拟器和高等级联盟页面仍以实际使用反馈验收。

自动刷本从出击到首次结算的正常加载、动画和自动战斗，不进行两分钟恢复检查。自动推图仍沿用常规轮询确认全部自动后的健康记录；失败、AP、网络、用户取消及各阶段总超时保护保持有效。

修复消耗 AP 作品导航被连续 TAP TO NEXT 弹层阻塞的问题：继续提示优先于背景 Logo、选择按钮与滑动；每次命中重新开始识别时间，不限制连续弹层的累计处理时长和数量。最后一次命中后持续观察五秒，无新提示才恢复导航；保留点击冷却、用户取消与网络安全检查。

界面语言设置
- 设置顶部的“界面语言 / Language”提供“简体中文”和“日本語”；点击保存并重启 GGEA 后生效，取消不会更改语言。
- 首次运行或旧配置未保存界面语言时，日文 Windows 使用日本語，其他系统语言暂回退简体中文；保存后不再跟随系统变动。
- 助手语言不会更改游戏区服、游戏包、识别素材、AP 方案或用户输入。游戏中的作品名沿用所选游戏资源语言；底层诊断日志、系统/第三方错误和远程更新说明保留原文。

在线更新使用方法
- 从 1.1.11.0 起支持动态备用源：初始列表为空；GitHub 可访问时自动获取并缓存维护者的新来源。旧的 1.1.10.0 不具备来源发现能力，须先升级到支持版本（GitHub 可用时可在线升级）。
- 备用更新源由维护者统一配置，用户无需设置。尚无可用来源且 GitHub 无法连接时，请稍后重试或手动安装正式包。
- 每次启动后台检查一次，发现新版时在设置按钮右上角显示小标记；点击设置后标记消失，并展示更新内容，不自动弹窗。检查失败不影响使用，可在设置页重试。
- 可以继续使用当前版本；只有主动点击“下载更新”才开始更新，没有强制下载。
1. 任务结束后打开“设置”，在顶部“软件更新”中点击“检查更新”。
2. 有新正式版时查看更新说明，点击“下载更新”；下载期间可取消，尚未修改当前安装。
3. “下载完成后自动重启安装”默认开启，勾选状态即时保存；开启时下载校验成功后直接重启安装，关闭时须点击“重启并安装”并确认。其他尚未保存的设置不会保存，请提前保存；下载期间可取消，校验失败不安装。更新器等待 GGEA 正常退出后安装，并在自检通过后重新启动。
4. 下载失败或 GitHub 限流时可稍后重试，也可点击“GitHub 发布页”手动下载。不会读取 GitHub Token，不支持断点续传或增量包；连接失败时尝试已配置的备用源。
5. 安装失败会尝试恢复旧版；更新中断后再次启动会提示恢复。若主程序无法启动，可双击安装目录中的 .ggea-update/runner/GGEA.Updater.exe 恢复。恢复完成前不要删除 .ggea-update；其中保留安装日志和旧文件备份。
6. 已保存的用户配置、AP 方案、作品坐标和额外私人文件保留；官方程序与模板按新包更新，被替换文件的原内容保留在备份中。首次须手动安装包含此功能的正式包；开发版和本地普通包只可检查版本。

强化培育关卡新增一次略过流程：确认左上角标题后，在右下区域识别 skip_all.png 并点击，再在底部按钮区域识别 execute.png 后执行；共用 SKIP RESULT、OK 与返回标题确认。暗态 skip_all_disabled.png 命中作为不可略过证据直接跳过，仅亮暗两种按钮均未命中时保留原四类逐项流程，确认窗口识别失败时停止，避免误点或重复执行。

修复自动推图略过后停在故事首次观看报酬弹窗的问题：每次 SKIP 后在底部按钮区域核对 OK 文字及完整按钮并点击，再以新截图确认返回选择关卡；观看关卡的执行确认和十五秒循环继续保留。两分钟静止巡查增加同一 OK 识别，可恢复未记录本次略过的奖励弹窗。重复弹窗有限点击且不会刷新静止计时，保留失败、AP、网络与取消保护。使用 MuMu 5556 当前奖励原帧回归。

自动推图为观看关卡增加十五秒循环：首次执行后等待十五秒点击画面中央，再从新截图识别右上角 SKIP 并确认底部执行按钮；略过后持续检查选择关卡、出击准备等返回入口，未确认返回则等待下一轮继续。执行确认暂未出现时结束本轮观察并重试，不因单轮漏识别直接停止；保留总超时、卡顿、取消、网络、失败与 AP 安全保护，普通出击流程不变。

修复主界面确认约需十九秒的问题：主界面默认采样及点击后观察间隔改为半秒，兼容修正旧配置中的五秒默认值，保留其他手动值与九十秒总预算。关卡编号、历史作品、出击准备、强敌次数及商店免费证据在候选出现后短间隔复核；全局继续动作缩短新帧确认前等待，保留独立点击冷却。连续帧、取消、识别阈值和钻石安全校验保持不变。

系统性优化关卡编号识别：将数字窗口约束到台座上方，使用白色笔画与局部背景抑制两条固定路径，后者保留灰度细节送入 OCR；完整字形、置信度和连续帧约束保持不变，编号或位置冲突时返回未知。缺号仍跟随游戏推进；历史节点已确认通过但缺号时，以总览关卡 100% 确认完成。新增真实浅色山体、沙漠及模拟增亮回归。

修正历史关卡战后编号未识别便停止的问题：沿用游戏自动选择下一关的行为，缺号时继续检查真实出击入口，不因缺号返回总览或中止。编号仍仅用于记录、去重与终点确认；保留明确已通过/锁定状态、实际战斗失败、取消及战斗次数上限保护。

修复历史 BOSS 难度标识位于视口边缘时反复上下滚动、无法找到挑战按钮的问题。保留被裁切卡片的难度与高度，仅用于定位；按目标标识 Y 坐标计算拖动距离，单标签先居中确认同难度两关，再重新识别完整状态和挑战按钮。边缘卡片不授权挑战，保留锁定、未知、取消与有界重试保护。

修复历史关卡 HARD 3 在浅色背景下编号漏识别并重复出击：编号定位失败时收紧白色笔画亮度，保留完整字形与 OCR 置信度门槛。历史节点有限重采样，缺号仍保留两帧已通过/锁定状态；战后无法确认新编号时复核总览 100%，未完成则停止，避免反复消耗 AP。

历史推图从第一关开始时，系列部队与自由部队各自动编制一次；历史 BOSS 的第一关独立执行同样初始化。首关初始化不依赖空槽或日常编制开关，恢复流程保留确认记录避免重复；中途续推沿用原策略，GUEST/观看入口无玩家准备页时不编制，保留标题确认、最低单位与地形安全校验。

补齐 AP 不足停止的 Windows 专属通知：出击 AP 弹窗、结算页无法再次出击及略过回复 AP 弹窗共用停止信号，覆盖自动刷本、主线/历史/强敌推图及每日/AP 消耗略过。通知不依赖正常任务收尾，同一执行只提醒一次并抑制重复结束通知；尊重系统通知开关与关窗状态，通知失败不改变原停止流程。

优化历史 BOSS 逐级推进：从底部 NORMAL 起按关卡顺序读取，遇到首个未完成且可挑战目标立即攻略，不再预扫描六关或每轮回顶查找。战后只在当前视口复核刚完成关卡的 CLEAR / COMPLETE，再向上一关继续；仅目标不在视口或游戏重置位置时滚动，保留锁定/未知停止、取消及作品总览双 100% 复核。

修复历史 BOSS 扫描依赖跨视口标题重叠而中止的问题。移除卡片标题字形比对与双帧重复识别，按同帧同难度两卡的上下位置确定六关顺序，仅以对应区域的 CLEAR / COMPLETE 判断完成；未完成时校验挑战按钮。缩短滚动距离以完整读取难度对，保留作品页面校验、低难度优先、取消与战后完成标记检查。

历史作品点击关卡后，同帧并行识别下载按钮与目标作品节点页 Logo，无需先等待其中一项超时。沿用允许下载设置：允许时点击一次下载并等待页面，未允许时取消并停止；弹窗优先于背景 Logo，最终仍须连续两帧确认目标作品与节点页，支持中止及下载后十分钟超时。

修复透明标题素材仍把透明区域当成黑色背景参与评分，导致第 08 MS 小队总览标题漏识别的问题。封装 AlphaMaskedTemplateMatcher，按 Alpha 有效像素复用灰度纹理与亮度双重校验，忽略透明背景并拒绝纯色伪匹配；保留 90% 门槛、作品身份与双帧复核。导航日志区分标题未确认、总览未确认与作品 Logo 未确认。

历史关卡作品列表倒序显示；添加目标左侧新增默认勾选的“攻略 BOSS”。选项随目标保存，取消后仅推进关卡并确认关卡 100%，随后继续队列；默认仍要求关卡和 BOSS 双 100%。

修复强敌战后奖励机体展示页的 TAP TO NEXT 漏识别：处理白色模型与文字粘连，保留灰度细节进行完整文字复核，保持原有平均与逐字置信度门槛。正常轮询、两分钟恢复检查和略过共用修复后的识别；增加原始奖励画面、连续六台奖励后返回选关及无进展停止回归。未操作实机点击，实际连续战斗体验仍需反馈确认。

完成历史作品自动推图：作品 Logo 复核后按攻略度先推进关卡至最终 HARD，再按 NORMAL、HARD、EXPERT 各两关的顺序推进六个 BOSS 关卡；每部分完成后返回作品总览，连续确认两项均为 100% 才切换队列目标。历史作品接入混合队列与统一编制、取消和安全保护，采用独立轨道布局与同帧身份校验；共享更新后的 CLEAR / COMPLETE 素材，未知、锁定或进度未前进时停止。

新增强敌来袭自动推图：按 NORMAL、HARD、EXPERT 的实际解锁及 CLEAR / COMPLETE 状态选择最高未通关难度，确认 EXPERT 通关后切换队列目标。自动推图新增主线／历史／强敌类型选择，支持混合队列；复用强敌导航及自动推图编制、战斗和安全保护，不消费略过次数，不进入 CHALLENGE 难度。

修复强敌来袭略过多台奖励机体时过早超时：每次识别并点击 TAP TO NEXT 后重新给予完整 20 秒识别时间，最多处理六次奖励继续，随后仍须确认 SKIP RESULT。保留识别阈值、取消与结果确认保护；补充六台延迟动画及续期上限回归，未进行实机游戏验证。

扩大自动推图 SKIP 识别范围至标准 1920×1080 画面的右上四分之一（x=960–1920、y=0–540），正常轮询与超时恢复共用该区域；保持识别阈值、点击和结算确认保护不变。
完善原型高达与铁球的路线图快捷查找：确认另一单位后最多定向拖动两次，每次拖动后重新识别目标，命中立即结束；两次均未命中则回到普通归位与逐行搜索，保留稳定确认、页面校验和取消保护。

修复自动推图 GUEST BATTLE 点击出击后停在确认弹窗的问题：直接出击与观看入口共用底部 320 像素的执行按钮识别，确认并点击执行后才进入下载和战斗流程；缺少执行按钮或用户取消时停止，不盲点。使用 MuMu 5558 高达 W 原始确认画面回放验证，未操作实机执行战斗。

仅在自动推图的作品选择中移除 ID 1（Mobile Suit Gundam）；共享作品配置、AP 消耗及其他功能保持可用，默认选择从剩余作品中确定。

完善自动推图同关接续：本次出击成功结算后，若返回仍选中上次关卡，则复核当前编号、两帧 NEXT 与目标，点击后确认新关卡，避免重复出击。区分 CLEAR 与 COMPLETE，两者均可作为通关与略过入口证据，略过仍检查实际按钮、次数与 AP。自动推图的 TAP TO NEXT 专用区域扩大为底部向上 300 像素，覆盖功能解放页及 HARD 共用的开场、结算和返回路径，其他任务维持 200 像素。推图与刷本连续两次各 2 分钟仍无正常流程进展时停止任务并保留画面；确认全部自动的正常战斗继续等待，失败和取消优先。增加真实文字与 CLEAR 素材、同关推进、截止边界及正常战斗回归，未执行连续实机战斗。

修复 MuMu 5558 在 HARD 结算后过早读取下一关：原刷本流程发送返回点击后，推图现在独立等待真实“选择关卡”标题，最多 60 秒，确认后才读取编号并计为完成；普通刷本语义不变。保留识别阈值、取消、网络及失败保护，超时不盲点、不猜编号。实际失败证据仍是战斗过渡帧；当前生产截图可识别 HARD 2 与出击准备，新增原像素回放及延迟返回、超时和取消回归。未执行连续实机战斗验收。

修复二倍速关闭后未正确开启：先确认中央双箭头字形，再按按钮内部青色／灰色像素判定状态，避免整图灰度与背景干扰。推图与刷本共用识别，推图不再依赖 AUTO 命中才检查速度；MENU 可见时不切换。点击后利用后续正常截图复查并记录真实状态，不把点击发送当成开启成功。加入用户灰色按钮原图、真实开启素材、MENU 同位置切换与无 AUTO 场景回归；未执行模拟器连续战斗验收。

为自动推图和自动刷本加入连续 3 分钟无阶段进展后的画面恢复。正常识别、点击顺序、等待时长及结算门禁保持原流程；到期才重新检查剧情、战斗、继续、结算或准备页，全部自动战斗继续等待，不因耗时达到三分钟而重启。推图恢复保留作品队列与已完成记录，返回页缺少结束证据时只重新读取真实进度，不虚增通关；刷本补点上一轮再次出击后仍须确认新开场，恢复不重复计数。同一阶段最多三次补救，耗尽后暂停额外重试并沿用原超时，未知画面不增加盲点。保留下载、编制、取消、AP、失败及网络保护。新增三分钟边界、恢复与正常流程点击序列回归；未执行模拟器连续战斗验收。

修复 MuMu 5558 自动推图跳过剧情后卡在 Z 高达选关页：返回页识别改为匹配完整白色标题字形与字间空隙，避免作品海报背景导致旧整图模板漏识别。保留 SKIP／结算后的返回门禁、最终 NORMAL 奖励包关闭要求及失败与取消保护。加入用户标题原像素回放、未结束不得完成、奖励包门禁及不完整／区域外标题拒绝回归；未执行模拟器连续战斗验证。

1. 首次设置

1. 将整个发布包解压到一个可写文件夹。不要只复制 GGEA.exe；它必须与 OpenCvSharpExtern.dll、config、resources 保持同级目录结构。
2. 启动 Android 模拟器，并确认游戏已安装。若模拟器提供 ADB 调试开关，请先开启。
3. 首次运行 GGEA.exe 自动从运行进程、安装注册表、常见目录和 PATH 检索 ADB。只有一个候选时自动选择；多个候选时优先选择可读取执行记录中最近运行的 ADB。系统记录缺失或受限时会提示无法判断，请在设置下拉列表确认。后续启动保留已保存的选择，不重复覆盖。
4. 检索失败时会提示并打开设置，请点击“浏览…”选择模拟器的 adb.exe（BlueStacks 为 HD-Adb.exe），点击“保存”后路径会保留在下拉列表中，重启仍可选择。点击取消则不保存本次编辑。便携版、非标准安装目录或受限目录可能需要手动选择。
5. 按需选择模拟器主程序并检查启动参数：MuMu 默认使用第一个安卓实例，雷电默认使用 launch --index 0；BlueStacks 会自动配对同一安装目录中的 HD-Adb.exe 与 HD-Player.exe。
6. BlueStacks 用户还需在模拟器“设置 → 高级”中启用 Android Debug Bridge 并保存；否则 GGEA 会显示针对性提示。
7. 选择当前游戏的区服与语言后保存设置（包名自动确定），返回主界面点击“刷新”，确认目标设备显示为可用状态。

2. 启动并进入游戏

已运行模拟器时，先在设备列表选择目标设备，再点击“启动模拟器 / 打开游戏”。程序会连接 ADB、等待设备可用并打开游戏。选定 ADB 或刷新后，程序仅保留已确认且启动身份一致的在线目标；首次发现、原目标离线或重启后须手动选择，不会自动换到其他账号。同一实例的 TCP 与 emulator-* 地址仅在 boot_id 一致时视为同一目标。执行任务前请确认选择的是目标账号所在的设备。设备品牌独立识别，MuMu 使用管理器实例信息补充识别，并按启动标识合并重复连接。

业务自动化当前要求模拟器输出 1920×1080 横屏截图；尺寸不符时会停止自动点击，但“截图”功能仍可用于检查和调整设置。“开发&强化一次”默认勾选，使用所选设备的截图与标准 ADB 拖动，不再按品牌禁用。进入路线图时保留游戏当前缩放，通过两张立绘模板及多尺度搜索找到目标；连续两帧稳定命中才点击，找不到、标题消失、达到搜索上限或取消时停止。

进入每日任务前，请先在游戏内手动确认账号、网络和活动弹窗均正常。遇到人机验证、数据同步或下载确认时，程序会停止自动操作；请手动处理后再重新开始。

3. 每日任务

1. 在“每日任务”列表勾选需要的项目，可拖拽调整执行顺序。
2. 点击“任务开始”后，程序会按列表顺序执行，并在流程之间返回主界面确认状态。
3. 需要中止时，点击“中止任务”按钮。中止后请先确认游戏当前页面，再重新发起任务。

推荐先仅勾选一个低风险项目验证设备和模板匹配正常，再逐步启用其余任务。

4. AP 消耗与关卡导航

1. 在“AP消耗”页选择或维护作品与 HARD 关卡，再保存需要的方案。
2. 作品坐标、模板和 stageSwipeCanvasDelta 必须在当前模拟器分辨率下验证；更换模拟器、窗口缩放或游戏版本后，请重新校准。
3. 导航优先使用整屏滑动；整屏滑动无法将作品落入安全点击区时，程序才会使用一次固定半屏滑动。
4. 出现点击错位、未解锁、标题识别失败或滑动异常时立即停止，不要连续重试。请保留 logs/ 中的日志以便排查。

5. 模板维护工具

“截图”“保存模板”和“测试模板”用于维护识别素材：先截取当前模拟器画面，框选稳定且有辨识度的区域，保存后在同一页面测试置信度与坐标。游戏 UI 更新后，旧模板可能失效，应重新采集并测试。

- 点击右上角设置旁的灯泡切换日间／夜间模式，偏好立即保存，下次启动自动恢复；首次运行默认夜间模式。

本机插件
- 关闭程序后将可信插件完整放入 plugins/<id>/，启动后在设置中启用并保存，再次重启生效。
- 插件具有与程序相同的本机权限，不是安全沙箱。安装、更新和卸载均在退出后进行。
- 配置保存在 config/plugins/；主程序在线更新保留插件。插件清理失败时停止新设备操作，可在设置中停用并重启。
- 旧版扩展配置会保留供插件导入。插件未安装或未启用时不执行扩展功能。
