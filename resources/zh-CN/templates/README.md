# 识别模板目录

本目录只放简体中文专属模板，PNG 格式。跨语言共用的素材放在 `resources/common/templates/`，不需要在本目录重复保留。

运行时优先识别本目录的同名素材；没有该文件时直接使用通用素材。本目录素材在当前帧未命中时，再按原阈值和区域补试一次通用目录的同路径同名文件；不会使用其他语言目录。

## 分类说明

模板按功能页面分类，新增模板时放入对应目录：

```text
templates/
├── entry/     启动流程：tap to start、TAP TO NEXT（活动奖励页/登录奖励页）
├── home/      主界面：主界面按钮激活/未选中状态模板、红点模板
├── common/    通用页面：返回、等级提升、奖励等模板
├── mission/   使命/任务页：领取按钮、挑战按钮、全部领取、每日 Tab
├── base/      个人基地：全部回收（可用/暗灰不可用）、结果弹窗 OK
├── shop/      商店：免费商品购买、确认购买、结果关闭
├── gift/      礼物：全部领取、关闭
├── develop/   开发：路线图、目标机体
└── safety/    安全锁：钻石图标模板
```

推荐通过 GGEA 内置的模板采集工具制作：

1. 在模拟器中打开目标页面，GGEA 中点击「截图」。
2. 在截图显示区按住鼠标左键拖选目标区域。
3. 输入模板名称，点击「保存模板」。
4. 在「测试模板」中选择刚保存的模板，验证 Confidence 与坐标。

模板应来自真实游戏截图，不要拆游戏资源。
