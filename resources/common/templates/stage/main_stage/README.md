## 当前识别与导航

- `WorkLogoVision` 复用项目已有 OpenCV 依赖解码 WebP。画布使用透明度遮罩、
  0.414 / 0.417 / 0.420 / 0.423 四个尺度，半分辨率搜寻五个候选，再原分辨率复核。
  除初代外，先合成亮灰底再缩放，以减少透明像素的颜色污染；初代保留严格不透明主体。
- 画布阈值为 0.80；初代单独标定为 0.78，不全局降低阈值。
  同位置出现分差不足 0.035 的竞争作品时拒绝歧义结果。
- 点击前要求目标连续两帧位置稳定（偏差不超过 5 像素）。
  左下角 `(0,830,720,250)` 及底部导航栏不允许作品点击，目标被遮挡时先拖动。
  目标不存在时用最高置信度作品推算一次拖动，之后重新识别，不累计假定移动量。
- 点击后在 `(123,120,510,180)` 内验证目标标题，并在同帧验证右下选择按钮。
  两项成立才点击选择，然后继续原 HARD 关卡确认流程；只有标题或只有按钮均不通过。
  SEED 家族标题额外比较相似作品，防止共用主体文字造成误选。
- 无作品时在 `(0,0,737,104)` 内检查 `../main_stage.png`，持续无结果或错误页面走
  主界面 → 关卡 → 主要关卡恢复。`../challenge_story.png` 来自实机 STORY 入口文字，
  用于拒绝同样带有“主要关卡”标题的挑战地图，不用于点击左下角。
  恢复前复用全局 TAP TO NEXT 识别处理解锁遮罩；无法确认主界面时停止。
- 导航最多观察 80 次、180 秒、恢复主界面 2 次，支持用户取消。

## 当前验证与限制

- 1920×1080 的 9 张巡检画面全部重跑生产识别器，覆盖 19 个作品。
  每个作品最佳样本分数范围 0.799～0.945，单帧全量识别约 2.4～2.9 秒，
  数值为本机样本结果，不是准确率或性能保证。
- 实机验证初代、哈萨维、SEED Recollection 的识图拖动、标题与选择确认；
  验证挑战地图经主界面重新进入普通地图并选中初代。只导航，不执行扫荡或消耗 AP。
- 自动测试覆盖真实标题 ROI、错误作品、初代弱对比样本、挑战模式拒绝、
  丢失点击/滑动、移动中目标、禁点边界、同帧验证、有限恢复和原 HARD 流程衔接。
- 目前仅校准 1920×1080 和当前地图缩放。其他分辨率停止操作；严重遮挡、
  新 Logo 或 UI 改版可能导致识别失败，需要重新采样。未遍历 19 个作品的详情页实机测试。
- 原始截图、对照图及实验程序位于忽略的 `research/logo-survey/` 和
  `research/logo-navigation/`；测试目录仅保留两个有明确回归用途的裁剪样本。

## 首次素材核对方法（历史记录）

- 使用用户提供的 WebP RGBA 素材，以缩放后 Alpha ≥ 245 的像素为遮罩，
  进行灰度零均值归一化相关匹配（ZNCC），未引入新的运行依赖。
- 初始尺度为 0.417，半分辨率搜索三个不重叠候选，再在原分辨率局部复核。
  上表在每个作品的最佳巡检候选附近，以 0.001 步长细化 0.380～0.450 尺度。
  表中分数是所选样本的匹配结果，不是成功率、稳定性保证或生产点击阈值。
- 机体及武器会遮挡 Logo，左下角固定入口会覆盖底排作品。
  哈萨维、F91、Narrative、Endless Waltz 等低分样本虽经画面核对确认身份，
  仍不能仅据此认为完整 Logo 已足以稳定驱动点击。
- SEED、Recollection 和 DESTINY 必须保留用于区分作品的后缀；
  不能通过统一裁掉 Logo 右侧来解决遮挡，也不能全局降低阈值来迁就低分样本。
- 首次核对仅登记素材对应关系；现已由独立 `WorkLogoVision` 接入 WebP 导航。
  原有 PNG 识别器与 `mobile_suit_gundam.png` 左端锚点保留供旧配置兼容使用。
- 原始截图、标注对照图及实验脚本位于本机 `research/logo-survey/`，
  属于忽略的实验产物，不随源码提交。
