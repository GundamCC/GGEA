# 略过后的玩家升级提示

`player_rank_up.png` 与 `rank_up_next.png` 采自 1920×1080 的实际玩家升级画面。
前者只包含固定的 PLAYER RANK UP 标题，后者只包含底部 TAP TO NEXT，
不包含玩家等级、AP 上限或 AP 数量等动态数字。

结果 OK 后先确认关卡返回证据。升级检测启动后，在标题区域 `(620,190,720,145)` 与底部提示区域 `(715,900,520,175)` 按原尺寸、1.05 倍和 1.025 倍匹配完整文字，局部灰度相关阈值为 0.92。首次命中标题后重新截图，同帧确认标题和提示才点击继续。随后持续确认标题消失并返回关卡。

正常返回预算用尽后，启用升级识别的流程额外恢复一次，最多 10 秒，只处理当前结算后的画面。取消或恢复超时后停止。

实机已验证关闭升级提示并返回关卡页。若关卡仍有剩余略过次数，
原有次数上限条件不会通过；本功能不改变略过次数或自动追加执行。
