# 免费培育包购买校验

使用用户提供的 `free.png`（303×40），替代已删除的 `text_free.png`。
在 1920×1080 画面指定区域 `(394,640,334,85)` 搜索完整“钻石＋免费”价格栏。
同时验证模板左右的钻石与文字特征，拒绝只有灰底相似的数字价格；特征从该文件生成，
不需要额外图标或文字素材。整栏及局部的 SSD 至少 0.92、NCC 至少 0.90。

同一帧必须命中该价格栏及其下方购买按钮，并连续两帧位置稳定才点击购买。
识别失败、缺少钻石、价格变成 200、其他卡片或底部提示显示免费时均不得点击。
免费商品检测最多 5 秒，未确认时返回主界面并继续后续每日任务，不中断整个任务队列。
最终确认使用独立的三态授权，不能把钻石风险未命中当作免费。

## 最终确认授权

`confirmDialog.png`、`confirmFreeStatement.png`、`confirmItem.png`、`confirmZeroCost.png`
裁自本地历史实机截图 `research/captures/premium_confirm.png`，分别校验确认购买标题、
“将使用钻石0个”完整声明、每日免费培育包名称及所需数量 0（含左侧空白）。
对应区域见 `resources/ui_layout/shop.json`。不要把单独一个“0”或商店列表的免费素材替代这些证据。
这里只支持已采集的 1920×1080 中文弹窗，其他弹窗必须先采集并验证独立证据，不能推断免费。

每个 8×8 像素块 RGB 平均差不超过 8，防止局部金额变化被大面积背景稀释。
最终按钮还须通过 SSD 0.98 和相同的分块校验；这些严格阈值可能安全拒绝未采集的视觉变化。
标题、商品、两个零价证据与按钮连续两帧确认才可购买，第二帧截图请求至点击前不得超过 1500ms。
点击位置来自第二帧按钮匹配结果，按钮移动、模板缺失、区域越界、截图失败均返回 Unknown 并停止。
钻石红字及已知余额区域红字为 RiskDetected，优先否决；图标缺失但其余免费证据完整时可以 SafeFree。

Unknown / RiskDetected 不再执行固定位置导航点击；诊断原图与原因写入
`%LOCALAPPDATA%/GGEA/diagnostics/shop/`。截图失败时只能保存原因，保存失败也不恢复购买。

回放基准保存在 `tests/GGEA.Tests/Fixtures/Shop/free_confirm.png` 和 `paid_confirm.png`，
后者来自 `research/captures/shop_confirm.png`（CAPITAL 付费购买，必须拒绝）。
测试在内存生成遮挡、漏图标、动画、相似按钮、价格变化和红字变体，这些变体不是新的实机采集。

截图回放已验证当前免费商品命中；将画面右侧真实 200 钻石 AP 包移动到首栏后拒绝。
该验证没有点击实际商品或执行购买。旧默认文字模板配置会迁移到 `free.png`。
